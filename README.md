# Sologuti – ১৬ গুটি

Sologuti is a browser-based version of the traditional Bangladeshi 16-piece strategy game.

## Play

Open the game: https://sajednsu-sketch.github.io/sologuti/

## Install on iPhone

1. Open the game link in Safari.
2. Tap the Share button.
3. Choose **Add to Home Screen**.
4. Tap **Add**. Launch Sologuti from the new Home Screen icon.

## How to play

- Choose **Play vs AI** or **2 Players**, then start a game.
- Select one of your pieces, then select a highlighted empty point.
- Captures are compulsory when available.
- If a capture leads to another capture, continue with the same piece.
- A player wins when the opponent has no pieces left or no legal move.

The game includes English/Bengali language options, sound controls, and three AI difficulty levels.

## Privacy

The current game does not require an account and does not include in-game analytics or advertising. See the [Privacy Policy](https://sajednsu-sketch.github.io/sologuti/privacy.html). GitHub Pages may process technical request information as part of hosting the website.

## Project status

This is a Progressive Web App (PWA). It can be installed from supported browsers. A native App Store release is a separate future step.
